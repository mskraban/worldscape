# Security policy

Worldscape is a static site plus a small, stateless image API. It stores no user data and has no accounts.

If you find a security problem (for example a way to make the API use unbounded memory or time), please report it privately through GitHub's **Report a vulnerability** button under the repository's *Security* tab rather than a public issue. You will get a reply within a few days.

Known, intentional limits: posters up to 2480 px wide, maps up to 3200 px per side and 7 megapixels, sheet music up to 2400 px, seeds up to 200 characters, response bodies up to about 4.4 MB.
